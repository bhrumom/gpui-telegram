## Interface Contracts

### 1. Theme & Avatar Layer (`M1`) ↔ All Desktop Views (`M2`–`M5`)
- **`theme::openbot_palette::OpenBotPalette`**: Canonical `383a35d2` semantic tokens (`bg_frame`, `bg_canvas`, `bg_sidebar`, `bg_surface`, `bg_surface_raised`, `bg_control`, `bg_control_hover`, `bg_control_active`, `border`, `border_strong`, `hover`, `text_primary`, `text_secondary`, `text_muted`, `text_dim`, `surface_light`, `text_on_light`, `accent`, `success`, `warning`, `danger`, `unread_surface`, `unread_text`, `badge_new`, felt badge stops) + `readable_chat_background(hex, is_dark)` & `solid_bubble_takes_dark_text(hex)`.
- **`theme::tdesktop_palette::TdesktopThemePalette`**: Synced with OpenBot monochrome dark/light surfaces for active desktop views while preserving `TdesktopThemeMode` Light/Dark/Tinted/Classic switching and exported baseline palette tests.
- **`components::avatar` & `components::grok_bot_avatar` & `components::bloub_avatar`**: Default bot visual renderer resolves to `PlushFeltRenderer` (`plush:<shape>`) when a bot has no custom photo URL; exposes `render_plush_bot_avatar(seed, shape, hue, color, size, mood, activity)` and `render_felt_status_badge(state)` (`Working3Balls`, `UnreadPlum(u32)`, `WaitingAmber`, `RespondedGreen`, `ErrorRaspberry`) plus `render_channel_avatar(members, layout, custom_icon, custom_hue, image_url, size)`.
- **`views::apple_sidebar::AppleAppSidebar` (`OpenBotPageRail` mode)**:
  - Fixed `52px` width (`OPENBOT_PAGE_RAIL_WIDTH = 52.0`) on `#0d0d0d` frame; preserves `APPLE_EXPANDED_WIDTH`/`APPLE_COLLAPSED_WIDTH` constants as needed while defaulting live rail rendering to `52px` icon-only `PageRail`.
  - Emits `AppleSidebarEvent` covering ALL destinations (`Chats`, `Community`, `Books`, `Music`, `Games`, `AppStore`, `MyCreations`, `Contacts`, `Calls`, `Workflows`, `Tasks`, `Schedule`, `Library`, `Usage`, `McpTools`, `RemoteComputer`, `Browser`, `OpenSettings`, `OpenAccount`, `TogglePin(section)`).

### 2. Sidebar & Create-Agent Studio (`M2`) ↔ `AppShell` (`M1`, `M3`, `M4`)
- **`views::chat_sidebar::ChatSidebar`**:
  - Preserves exported `pub const DEFAULT_WIDTH = 288.0`, `COLLAPSED_WIDTH = 64.0`, `ROW_HEIGHT = 62.0` while using OpenBot sidebar runtime defaults (`OPENBOT_SIDEBAR_DEFAULT_WIDTH = 280.0`, `min = 128.0`, `max = 400.0`, `compact = 88.0`, hysteresis `110.0 / 118.0`).

  - Interactive OpenBot `FirstAgentSetup` studio state (`selected_color_idx`, `selected_shape_idx`, `name`, `purpose`, `model_id`, `template_recommendations`) mounted inline inside `#1a1a1a` canvas (or modal fallback) and wired directly to `AppShell`'s live `CreateManagedBot` + `provision_openbot_agent_for_fabushi` flow.
